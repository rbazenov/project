# Портал школьных музеев — Всероссийский конкурс школьных музеев «Знание»

Одностраничное веб-приложение с интерактивной картой России, каталогом школьных
музеев по регионам и статусами участников конкурса.

## Запуск

Файл `index.html` самодостаточен — открывается двойным кликом или по
`file://`. Все данные (топология, геометрия регионов, музеи, фотографии)
встроены в HTML, дополнительных ресурсов загружать не нужно.

## Структура

- `index.html` — вся логика, стили, данные и фотографии

## Возможности

- Карта России с 84 регионами; клик по региону фильтрует каталог.
- 283 школьных музея с карточками и фотогалереей (карусель с прокруткой колесом
  мыши, циклический переход, раскрытие по кнопке «Ещё»).
- Поиск по регионам.
- Фильтрация по статусу участия.
- Лайтбокс для просмотра фотографий в полном размере.
- Адаптивная раскладка.

## Аналитика

На страницу подключён счётчик **Яндекс.Метрики № 113767864** (см. `index.html`,
блок «АНАЛИТИКА — Яндекс.Метрика» в `<head>`). Что уже включено:

| Настройка счётчика | Что даёт |
| --- | --- |
| `webvisor: true` | Вебвизор — запись всех действий пользователя (клики, движения, скроллы, заполнение форм) |
| `clickmap: true` | Карта кликов в отчётах |
| `trackLinks: true` | Переходы по внешним ссылкам и скачивание файлов |
| `accurateTrackBounce: true` | Точный показатель отказов |
| `trackHash: true` | Переходы по якорям/секциям (`#catalog`, `#how` и т.д.) |

### Как сменить номер счётчика

Один раз в `<head>`: `window.YM_ID = 113767864;` и такой же номер в `<noscript>`-пикселе
(`https://mc.yandex.ru/watch/113767864`). Больше нигде номер не встречается.

### События (цели), которые отправляет страница

Все действия уходят через `portalAnalytics.reach("имя_цели", {параметры})`.
**Чтобы событие появилось в отчёте по целям, создайте цель один раз в интерфейсе
Метрики:** Настройки → Цели → «Событие JavaScript» → идентификатор цели = имя из таблицы
(первые 10 целей доступны на бесплатном тарифе; остальные события всё равно видны в
Вебвизоре и в отчёте «События»).

| Цель | Когда срабатывает | Параметры |
| --- | --- | --- |
| `page_ready` | Страница загружена | `title`, `viewport`, `referrer` |
| `section_view` | Блок впервые попал в зону видимости | `section`, `label` |
| `scroll_25` / `scroll_50` / `scroll_75` / `scroll_100` | Глубина прокрутки страницы | `depth` |
| `region_select` | Выбран регион (список или карта) | `region`, `source` (`list`/`map`), `museums`, `okrug` |
| `museum_open` | Открыта карточка музея | `museum_id`, `museum`, `region`, `status`, `source` |
| `museum_close` | Карточка музея закрыта | `museum_id`, `museum`, `region` |
| `photo_open` | Открыт лайтбокс с фотографией | `museum`, `photo`, `total`, `source` |
| `photo_switch` | Переключение фото в лайтбоксе | `museum`, `direction`, `photo` |
| `photo_close` | Лайтбокс закрыт | `museum`, `photo` |
| `photos_toggle` | Кнопка «Ещё»/«Скрыть» в галерее | `museum`, `action` |
| `filter_status` | Фильтр по статусу (легенда или сайдбар) | `status`, `action` (`on`/`off`), `place` |
| `search_region` | Поиск региона (через 0,9 с после ввода) | `query`, `results` |
| `map_zoom` | Кнопки и колесо мыши на карте | `action` (`zoom_in`/`zoom_out`/`reset`/`wheel`), `level` |
| `map_drag` | Перетаскивание карты | `zoom` |
| `checklist_download` | Скачан чек-лист «Практика музеев» | `museum_id`, `museum`, `region` |
| `video_play` / `video_error` | Запуск ролика / файл не найден | `file` |
| `login_click` | Кнопка «Войти» | `place` |
| `menu_toggle` | Бургер-меню | `state` |
| `nav_click` | Пункт мобильного меню | `label`, `href` |
| `cta_click` | Размеченные ссылки: hero-кнопки, шапка, футер (`data-track="…"`) | `label` |
| `ui_click` | Любой остальной клик по кнопке/ссылке/чекбоксу | `label`, `tag`, `id`, `cls`, `href` |
| `session_summary` | Уход со страницы/скрытие вкладки | `seconds`, `clicks`, `events`, `max_scroll`, `sections_seen` |

Чтобы разметить новую ссылку или кнопку, достаточно добавить атрибут
`data-track="понятное_имя"` — событие `cta_click` уйдёт автоматически.

### Отладка

- Откройте страницу с параметром `?analytics=debug` — все события печатаются в консоль.
- История событий текущей сессии доступна в консоли: `__analyticsLog`.
- Аналитика полностью изолирована: если `mc.yandex.ru` заблокирован или страница
  открыта с `file://`, ошибки глушатся и интерфейс работает как обычно.
- Проверка «в живую»: откройте вкладку «Вебвизор»/«Мониторинг» в Метрике через
  несколько минут после визита, либо в отчёте «Содержание → События».
